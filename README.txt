FIELDNOTES — CLASSROOM ACTION RESEARCH WEBSITE
================================================

FILES
- index.html       Overview / home page
- purpose.html     Purpose and significance
- proposal.html    Major proposal components and proposed Weeks 1–7 timeline
- cycle.html       Interactive action research cycle
- resources.html   Required information, resources, data processes, and checklist
- style.css        Shared responsive styling
- script.js        Mobile navigation and page interactions

HOW TO RUN IN VS CODE
1. Extract the ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Install/use the Live Server extension if you have it.
4. Right-click index.html and choose "Open with Live Server".
5. Use the navigation menu to move between the separate pages.

NOTES
- The website uses Google Fonts, so an internet connection is needed for those fonts.
- The content describes the Weeks 1–7 schedule as a proposed timeline. Adjust it to match the approved research plan.
- Confirm school/institutional requirements for permission, consent, assent, and safeguarding before collecting student data.
- The website uses illustrative wording; adapt it to the exact details of your approved research proposal.
